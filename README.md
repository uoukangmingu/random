# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 지옥 모드 이스터에그 HQ 개선
- 낮/밤 모드 버튼을 10초 안에 6번 누르면 지옥 모드 발동
- 지옥 모드에서는 새로고침 전까지 낮/밤 변경 불가, 사운드 끄기 불가, 볼륨 슬라이더 잠금
- 지옥 모드 BGM을 더 기괴하고 불쾌한 방향으로 재설계
- 음악 템포가 갑자기 빨라지거나 느려지고, 멈칫거리는 구간과 긴 정적 구간이 무작위로 섞이도록 수정
- 중간중간 비명 같은 스팅어, 저음 럼블, 고주파 노이즈, 짧은 화면 글리치 발생
- 지옥 모드 색감을 어두운 방 안의 회색 조명 같은 저채도 팔레트로 재설계
- UI 요소는 어두운 상태에서도 잘 보이도록 대비와 경계선을 강화
- VHS 스캔라인, 치직거리는 노이즈, CRT 비네팅, 옛날 TV식 볼록 화면 느낌 추가
- 지옥 모드 전용 마우스 커서 적용
- JS 추적형 커서가 아니라 CSS 커서로 처리해 마우스 지연 문제 방지
