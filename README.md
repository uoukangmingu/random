# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 운 게임 메뉴 반복 표시 문제 수정: 일반 그리드에서는 기존처럼 운 게임 8개만 표시
- 운 게임 메뉴창에서만 낮모드 카드의 이모지 칸을 밤모드 위치 기준처럼 조금 위로 올림
- 낮/밤 모드 전체 크기·레이아웃 통일 패치 유지
- STAY CLICK 설정 화면의 시작/리셋 버튼 겹침 및 가림 현상 수정 유지
- STAY CLICK 화면 상단에 `피지컬 목록으로` 복귀 버튼 추가 유지
- 게임 화면에서 우측 유틸리티 버튼이 콘텐츠를 덮는 문제 완화 유지
- 낮은 높이의 노트북 화면에서 STAY CLICK 레이아웃 압축 보정 유지
- JS 게임 로직은 변경하지 않음
- 이미지/영상 에셋은 `assets/` 폴더에 포함됨

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
