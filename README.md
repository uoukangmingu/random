# 스포츠관광 국가별 문제풀이 프로그램

수록 국가: 핀란드, 캐나다, 미국, 호주, 필리핀, 중국, 일본, 한국

## 실행 방법
1. 압축을 푼다.
2. `index.html`을 브라우저로 연다.
3. 국가와 문제 수를 선택하고 문제를 푼다.

## 기능
- 국가별 출제 필터
- 10 / 20 / 40 / 전체 문제 출제
- 보기 섞기
- 많이 틀린 문제만 다시 풀기
- 오답 기록 localStorage 저장
- 많이 틀린 문제를 3회 연속 맞히면 기록에서 제거


## 추가 기능
- 정답 암기 모드
  - 전체 문항을 랜덤 순서로 보여줌
  - 문제와 보기를 보면서 정답이 바로 표시됨
  - 문제를 직접 풀지 않고 문제-정답을 동시에 암기 가능
  - 이전 / 다음 / 다시 섞기 지원


## 정답 암기 모드 문제 순서 선택
- 랜덤: 전체 문항을 무작위로 표시
- 출제유력순: 출제자 성향을 반영해 정책·시사점·장소성·대표사례·비교 문제를 앞에 배치
- 어려운 순: 개념 비교, 정책 구조, 지속가능성, 유형 구분처럼 헷갈리는 문제를 먼저 표시
- 쉬운 순: 단순 지명·종목·도시·항공사·대회명 암기 문제를 먼저 표시
