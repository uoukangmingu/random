# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- `담아라!` 게임 진행 중 운 메뉴/이전 화면으로 돌아가도 구슬 낙하음과 충돌음이 계속 재생되던 문제 수정
- 게임1 화면을 벗어날 때 남은 구슬 생성 타이머, 정착/결과 감시 타이머, 화면 밖 구슬 바디를 정리하도록 보정
- 구슬 충돌 효과음은 `담아라!` 화면이 실제로 활성화되어 있을 때만 재생되도록 안전장치 추가
- 기존 수정사항 유지: 운 게임 메뉴 8개 표시, 밤모드 경마 참가자별 색상, 음향 튜닝, 풍선 차례 색상, 압력 표시 제거, 작아지는 원 랜덤 이동 등

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
