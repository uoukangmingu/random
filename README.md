# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 이용 환경에 따라 제대로 표시되지 않거나 깨질 우려가 있는 이모지를 자동 대체하도록 보강
- 캔버스 기반 이모지 지원 검사 + 위험 환경용 보수적 대체 로직 추가
- 동적으로 생성되는 게임 화면/팝업/안내 문구의 이모지도 자동 검사
- 모바일 세로 경마 트랙, 아래 방향 경주, 이름/상태 숨김 유지
- 홈 배너 광고 제거 유지

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
