# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 볼 배틀 캔버스 렌더링을 물리 계산과 분리해 모바일·사무용 PC에서는 약 30fps로 제한
- 볼 배틀 전용 캔버스 해상도 상한을 모바일 0.7, 저사양 PC 0.85, 일반 PC 1.1로 경량화
- 충돌마다 발생하던 랭킹 전체 재생성, HP 라벨 강제 레이아웃, 과도한 데미지 DOM 효과 제거·제한
- 안전 구역 DOM 갱신과 HP 라벨 위치 갱신을 성능 등급별로 묶어서 처리
- 볼 배틀 종료 즉시 물리 러너와 연속 캔버스 렌더링을 정지해 결과 화면의 유휴 CPU 사용 제거
- 사무용 PC에서 커서가 사라지던 문제 수정
- 모바일·사무용 성능 모드에서도 기존 낮/밤 테마 배경 복원
- 모바일·저사양 사무용 PC 자동 성능 등급 적용
- 모바일에서는 캔버스 해상도, 물리 개체 수, 화면 갱신 빈도, 입자 수를 별도로 축소
- 보이지 않는 게임 화면의 물리엔진·타이머·DOM 재렌더링 중단
- 곰찾기 영상 PC 720p / 모바일 540p 분리 및 포스터 WebP 경량화
- 압축된 `script.min.js`, `style.min.css`를 실제 실행 파일로 사용
- Matter.js를 `assets/matter.min.js`에 포함해 외부 CDN 대기 제거
- 지옥 모드 이스터에그 HQ 개선
- 낮/밤 모드 버튼을 10초 안에 6번 누르면 지옥 모드 발동
- 지옥 모드에서는 새로고침 전까지 낮/밤 변경 불가, 사운드 끄기 불가, 볼륨 슬라이더 잠금
- 지옥 모드 BGM을 더 기괴하고 불쾌한 방향으로 재설계
- 음악 템포가 갑자기 빨라지거나 느려지고, 멈칫거리는 구간과 긴 정적 구간이 무작위로 섞이도록 수정
- 중간중간 비명 같은 스팅어, 저음 럼블, 고주파 노이즈, 짧은 화면 글리치 발생
- 지옥 모드 색감을 어두운 방 안의 회색 조명 같은 저채도 팔레트로 재설계
- UI 요소는 어두운 상태에서도 잘 보이도록 대비와 경계선을 강화
- VHS 스캔라인, 치직거리는 노이즈, CRT 비네팅, 옛날 TV식 볼록 화면 느낌 추가
- 지옥 모드 전용 마우스 커서 적용
- JS 추적형 커서가 아니라 CSS 커서로 처리해 마우스 지연 문제 방지

## 주의

`script.js`와 `style.css`는 유지보수용 원본이며, 실제 사이트는 각각의 `.min` 파일을 읽는다. 원본을 수정한 뒤 배포할 때는 압축 파일도 다시 생성해야 한다.
