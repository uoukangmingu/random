# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 러시안 룰렛 빨리감기 사용 중 우측 상단에 `빨리감기 x3` 표시가 뜨도록 수정
- 경마/볼 배틀과 동일한 표시 방식으로 러시안 룰렛 스테이지 카드에 빨리감기 상태 배지 적용
- 기존 수정사항 유지: 이모지 깨짐 방지, AdSense 기본 코드, SEO 메타 태그, 볼 배틀 크게보기 비율 보정, 운 게임 메뉴 8개 표시, 밤모드 경마 참가자별 색상, 음향 튜닝, 풍선 차례 색상, 압력 표시 제거, 작아지는 원 랜덤 이동, 담아라 화면 이탈 소리 버그 수정 등

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
