# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 풍선 불기에서 풍선 색이 현재 차례 참가자의 색으로 바뀌도록 수정
- STAY CLICK 화면 상단의 `← 피지컬 목록으로` 버튼 제거
- 풍선 불기 게임에서 현재 압력 표시 바 제거
- 풍선 안 숫자/퍼센트 표시를 `READY / HOLD / POP!` 상태 문구로 변경
- 풍선이 터지기 직전임을 알려주는 경고 효과음 호출 제거
- 풍선 경고/위험 단계의 시각적 강조 효과 제거
- 작아지는 원 게임에서 원이 시작 시 및 성공 터치 후 박스 안 랜덤 위치로 이동하도록 수정
- 운 게임 메뉴 반복 표시 방지 패치 유지
- 낮/밤 모드 전체 크기·레이아웃 통일 패치 유지
- JS 문법 검사 통과

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
