# 랜덤 룰렛 v3.32

기존 낮·밤 배경, 색감, 둥근 카드, 손글씨 제목과 13개 게임 구성을 유지했습니다. 이번 버전은 진행 문구가 한 줄과 여러 줄 사이에서 바뀔 때 화면과 박스가 순간적으로 늘었다 줄어드는 문제를 수정했습니다. 기존 원판 속도 배율, SPIN/STOP, 카드 후반 공개 순서, 음악, 메뉴 중앙 정렬, 담아라! 수정도 모두 포함합니다.

## 이번 업데이트: 문구 변경 시 화면 흔들림 수정

- 안내·상태·결과 영역에 역할별로 2~3줄 공간을 확보합니다. 작은 화면의 주요 상태 안내는 4줄, 보조 안내는 필요한 경우 3줄을 사용해 문구가 바뀌어도 주변 버튼과 박스가 움직이지 않습니다.
- 긴 이름과 문구는 줄바꿈하며, 확보한 공간을 넘으면 해당 안내 영역에서 스크롤해 전체 내용을 확인할 수 있습니다. 키보드 초점도 제공합니다.
- 단계·차례 배지의 폭을 일정하게 만들어 옆 제목이 갑자기 줄바꿈되지 않게 했습니다.
- 카드 배틀은 참가자별 안내가 바뀌거나 마지막 카드 공개 후 사라져도 같은 공간을 유지합니다.
- 볼 배틀은 PC에서 긴 안내문 때문에 일시정지·크게 보기 버튼이 아래로 밀리던 배치를 수정했습니다.
- 풍선·폭탄·작아지는 원의 작은 화면과 STAY CLICK의 높이가 낮은 PC 화면은 필요한 만큼 세로 스크롤됩니다. 고정된 화면 높이가 안내문을 가리지 않습니다.
- 성능 설정과 공용 목록의 안내·오류 문구에도 같은 높이 유지 방식을 적용했습니다.

변경은 CSS의 공간 배분과 안내 요소 속성에 집중했습니다. 매 프레임 텍스트를 측정하는 처리는 추가하지 않았습니다. 검증 조건과 결과는 `QA_REPORT_v3.32.md`에 있습니다.

## v3.31 하단 겹침 수정

- 모바일 성능 모드의 여백 설정이 조작바 공간을 덮어쓰던 오류를 수정했습니다.
- 메인·게임 목록에서는 설정·이전 버튼을 본문 다음의 실제 하단 영역에 배치합니다. 페이지 번호와 스와이프 안내를 가리지 않습니다. 내용이 긴 화면은 자연스럽게 세로로 스크롤됩니다.
- 게임 화면에서는 하단 고정 조작바를 유지하고, 모바일 성능 모드에서도 필요한 아래 여백을 확보합니다.
- 설정창은 하단 버튼 위에 열리며 본문의 높이를 밀어 바꾸지 않습니다.
- 작은 화면에서 페이지 번호와 스와이프 안내가 필요하면 줄바꿈됩니다.

이번 수정의 재현 조건과 확인 결과는 `QA_REPORT_v3.31.md`에 있습니다.

## v3.30 전체 게임 개선

- 공통: 좁은 화면에서 제목 → 설정 → 플레이 순서로 재배치하고 중첩 여백을 줄였습니다. 안내문·숫자 입력 가독성, 터치 영역, 결과 팝업의 세로 스크롤을 보완했습니다.
- 모바일: 설정·이전 버튼을 별도 하단 조작 영역에 배치하고, 화면 하단에 여유 공간을 확보했습니다. 처음 화면의 사용할 수 없는 이전 버튼은 숨깁니다.
- 이동: 게임 시작 후 작은 화면에서 플레이 영역을 보여주고, 목록으로 돌아가면 선택했던 카드의 위치·키보드 초점을 복원합니다.
- 입력: 한국어 조합 확정 Enter로 시작되는 문제를 막았습니다. 참가자 입력과 도움말을 연결하고 인원수 입력에 숫자 키보드를 적용했습니다.
- 카드 배틀: 참가자별 공개 안내를 복구했습니다. 카드 이름에 참가자·카드 종류·공개 상태를 표시하고 뒷면일 때 보조기술에 카드 값이 노출되지 않게 했습니다.
- 주식게임: 금액 조절 버튼을 44px 이상으로 확대하고 3열로 정리했습니다. 단위와 선택 상태를 명확히 하고, 키보드 조작 후 초점을 유지합니다. 금액 입력 전에도 선택한 종목 수를 정확히 표시합니다.
- 담아라!: 좁은 PC 창도 설정과 낙하판이 차례로 배치됩니다. 240px 폭 물리 보드도 낙하·리셋·재진입 검사를 통과했습니다.
- 곰찾기: 재생 중 리셋을 막던 투명 덮개를 제거했습니다. 재생 버튼의 중복 실행 잠금은 유지합니다. 참가자 수의 소수 입력도 거부합니다.
- 풍선: 작은 PC 창에서도 참가자 설정을 표시합니다. 휴대폰에서는 기존 넘겨주기 화면을 유지합니다.
- STAY CLICK·폭탄·작아지는 원·사다리: 기기 판정을 메뉴와 통일해 터치 PC나 큰 태블릿에서 표시와 실제 실행 조건이 달라지던 문제를 수정했습니다.
- 리셋 확인창: 리셋과 화면 이동의 제목·확인 버튼 문구를 구분했습니다.

상세 검증 범위는 `QA_REPORT_v3.30.md`를 참고하세요. 13개 모드의 소스를 검토했으며, 모바일 폭의 브라우저 확인은 실제 휴대폰 테스트를 대신하지 않습니다.

### 원판 조작

항목 설정 영역의 **회전 속도 배율**에 숫자를 입력합니다. 1배는 초당 14바퀴, 2배는 28바퀴, 10배는 140바퀴의 계산상 회전 속도입니다. 2.5처럼 소수도 사용할 수 있습니다. 속도는 시작 전과 회전 중 모두 조절할 수 있고, STOP 후에는 배율에 맞는 회전 거리를 두고 약 4.8초 동안 감속합니다. 속도 설정은 당첨 확률에 영향을 주지 않습니다. 빈 값이나 범위를 벗어난 값은 안내하고 시작을 막습니다. 모바일에서는 원판 아래 **항목 · 속도 설정**을 누르면 설정 영역으로 이동합니다.

중앙 SPIN과 아래 SPIN 버튼은 같은 역할입니다. 회전이 시작되면 둘 다 STOP으로 바뀌며 어느 쪽을 눌러도 감속합니다. 감속 중에는 추가 입력을 막고, 결과가 나오면 SPIN으로 돌아옵니다. 자동 종료 시간은 없습니다. 바로 STOP을 누르더라도 짧은 가속을 마치고 감속합니다.

추첨 가중치와 결과 기록·재추첨·당첨자 제외 기능은 유지했습니다. STOP은 감속 시점을 정하며 결과는 등록한 가중치에 따라 무작위로 결정됩니다. 화면을 벗어나 종료하면 취소된 추첨을 기록하지 않습니다. 다른 탭으로 이동하면 회전 시간이 일시 정지됩니다.

원판의 속도는 기기의 모션 감소 설정과 관계없이 입력한 배율을 따릅니다. 기기의 모션 감소 설정은 배경·결과 장식 애니메이션에 계속 적용됩니다. v3.27에서 모든 배율을 초당 0.6바퀴로 고정하던 경로를 수정했습니다.

회전 중 배율을 변경하면 약 0.26초 동안 새 속도로 부드럽게 전환합니다. 각도가 갑자기 튀거나 추첨이 재시작되지 않습니다. 잘못된 입력을 편집하는 동안에도 STOP을 사용할 수 있습니다. 고속에서는 각도에 따른 회전 잔상을 표시하고, 감속하면 원래의 선명한 원판으로 돌아옵니다. 잔상 이미지는 최대 512×512 크기 5단계를 필요할 때 한 번씩 생성해 재사용하며 매 프레임 다시 그리지 않습니다.

## 유지한 개선

- 원판은 프레임 기반 transform을 사용합니다. 회전 중에는 원판과 저장한 잔상 이미지의 각도를 바꾸며, 잔상 강도가 달라질 때만 필요한 이미지를 교체합니다.
- PC는 입력과 원판의 2열, 작은 화면은 원판과 조작부를 먼저 보여줍니다. 항목 수정 바로가기, 접이식 기록, 재추첨·당첨자 제외 기능을 유지했습니다.
- 당첨자를 제외해도 다음 추첨·편집 전까지 직전 원판과 결과를 유지합니다. 남은 항목이 2개면 제거할 수 없습니다.
- 공용 목록 저장·불러오기, 잘못된 가중치·중복 입력 처리, 결과·설정·입력 초안 저장을 유지했습니다.
- 배경음과 효과음 슬라이더, 키보드 포커스, 터치 영역과 첫 로딩의 중복 실행·재시도 처리를 유지했습니다.
- 게임 코드 압축, 첫 화면의 지연 로딩, 캔버스 해상도 조절, 비활성 화면의 불필요한 렌더링 억제를 유지했습니다.

## 소스 수정·재빌드

```sh
npm ci
npm run build
npm run check
```

빌드는 최상위 실행 파일과 `dist/`를 갱신합니다. `npm run check`는 정적 검사와 Node 모의 실행 검사를 수행합니다. 브라우저 자동 검사는 포함하지 않습니다.

| 수정 대상 | 원본 파일 |
| --- | --- |
| 기존 게임과 공통 처리 | `script.js` |
| 원판 룰렛 | `src/games/wheel.js` |
| 새 게임 규칙 계산 | `src/shared/gameplay-rules.js` |
| 음악 악보·악기·재생기 | `src/shared/soundtrack.js` |
| 게임 목록 조건 | `src/games/registry.js` |
| 화면 HTML | `src/index.template.html` |
| 기존 디자인 | `style.css` |
| 공용 기능 디자인 | `src/styles/features.css` |
| 디자인 보완·새 단계 표시 | `src/styles/polish.css` |
| 공용 목록·설정·로딩 | `src/shared/` |
| 화면 이동·초점·작은 화면 시작 안내 | `src/shared/interface-ux.js` |

`src/games/`의 core, bootstrap, game1~7, physical-games는 `script.js`에서 자동 분리되므로 직접 수정하지 마세요. 최상위 index, shell, runtime, app-markup도 생성 파일입니다. 빌드가 만드는 v3.21 이름의 번들은 기존 검사와의 호환용이며 실제 화면은 v3.32 파일을 사용합니다.

배포용 ZIP에서는 이전 실행 파일, 중복 호환 번들, node_modules, dist와 임시 검사용 화면을 제외했습니다. 편집 원본과 빌드·검증 스크립트는 포함했습니다. 검사를 다시 실행하려면 먼저 위 순서대로 빌드하세요.

## 확인 범위와 저장

공용 목록·입력·기록·설정은 현재 브라우저에 저장됩니다. 브라우저 데이터를 지우면 함께 삭제되며 여러 기기 사이에 자동 동기화되지 않습니다.

새 서비스 워커는 진행 중인 탭을 강제로 교체하지 않고 기존 탭이 닫힌 뒤 활성화됩니다. 아직 열지 않은 게임은 오프라인에서 실행이 제한될 수 있습니다.

이번 버전의 확인 범위는 `QA_REPORT_v3.32.md`, 파일 용량은 `PERFORMANCE_COMPARISON.json`을 확인하세요. 실제 iPhone·Android의 터치와 기기별 FPS는 측정하지 않았습니다.
