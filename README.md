# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 기본 이모지는 그대로 유지하고, 실제로 깨지거나 표시 불량으로 감지되는 환경에서만 대체되도록 수정
- 게임별 대체 이모지를 서로 겹치지 않게 재정리
- 대체 이모지는 각 게임 콘셉트에 맞게 변경: 담아라=양동이/그릇, 경마=말, 카드=스페이드 카드, 볼 배틀=공, 러시안 룰렛=타깃, 주식=상승 차트, 사다리=상하 이동, 곰찾기=곰 등
- 기존처럼 대체 이모지도 다시 표시 가능 여부를 검사하고, 그것마저 깨질 경우 짧은 텍스트로 최종 대체
- 운/피지컬 선택 메뉴 이모지 대비 개선, 모바일 세로 경마, 아래 방향 경주, 이름/상태 숨김 유지
- 홈 배너 광고 제거 유지

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
