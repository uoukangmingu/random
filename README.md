# Random Roulette Webapp

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열면 실행된다.

## 이번 버전 수정 요약

- 낮 모드에서 QR코드가 두 장 겹쳐 보이던 문제 수정

- 데스크톱 홈 화면에서 메뉴 박스 왼쪽에 QR코드 기본 노출 추가
- QR코드는 모바일/터치 환경에서는 숨김 처리
- 낮/밤 테마별로 눈부심을 줄인 고대비 QR 이미지 적용

- 모바일 스와이프 중 버튼 클릭음이 잘못 재생되는 문제 수정
- 버튼 효과음을 `pointerdown` 즉시 재생하지 않고 실제 `click`이 확정될 때만 재생하도록 변경
- 터치 이동 거리가 일정 이상이면 스와이프로 판단해 직후 클릭음을 차단
- 볼 배틀 모바일 세로 화면에서 공 크기를 상대적으로 작게 표시하는 수정 유지
- 기본 이모지는 그대로 유지하고, 실제로 깨지거나 표시 불량으로 감지되는 환경에서만 대체되도록 수정 유지
- 운/피지컬 선택 메뉴 이모지 대비 개선, 모바일 세로 경마, 아래 방향 경주, 이름/상태 숨김 유지
- 홈 배너 광고 제거 유지

## 주의

`담아라!`, `볼 배틀`은 Matter.js CDN을 사용한다. 오프라인 또는 CDN 차단 환경에서는 실행되지 않을 수 있다.
